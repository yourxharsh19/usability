# UsabilityHub Clone

A responsive clone of the UsabilityHub homepage, built with HTML, CSS, and JavaScript. This project demonstrates modern web design capabilities, responsive layouts, and interactive elements.

🔗 **Live Demo:** https://yourxharsh19.github.io/usability/

## Features

-   **Responsive Design**: Fully responsive layout that adapts to desktops, tablets, and mobile devices.
-   **Mobile Navigation**: Interactive hamburger menu for mobile devices.
-   **Modern Aesthetics**: Clean typography, hover effects, and a professional color palette.
-   **Flexbox Layouts**: Utilizes CSS Flexbox for efficient and flexible component alignment.

## Tech Stack

-   **HTML5**: Semantic markup for better structure and SEO.
-   **CSS3**: Custom styling with variables, media queries, and animations.
-   **JavaScript**: Simple DOM manipulation for the mobile navigation toggle.
-   **Font Awesome**: Icons for UI elements.
-   **Google Fonts**: "Poppins" and "Roboto" fonts for typography.

## Project Structure

```text
├── index.html      # Main HTML structure
├── style.css       # Core styles and desktop layout
├── media.css       # Responsive media queries
├── script.js       # Mobile menu functionality
└── assets/         # Images and icons
```

## How to Run

1.  Clone the repository or download the source code.
2.  Open `index.html` in your web browser.
3.  Resize the browser window to test responsiveness.
